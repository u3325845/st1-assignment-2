Reflection

What did you build before using AI?

Before using AI, I built a simple version of the code that focused only on the necessary data-gathering functionality, without accounting for anything beyond the obvious cases. It included minimal error handling and had several loopholes.

What did AI teach you?

AI taught me how to consider other possibilities and possible problems and how to use error handling in a proper manner.It also taught me to write the code in a simpler and understandable way while keeping it effective as the code doesn't need to be complicated to be efficient.

Did AI make  assumptions?

Yes, for example, AI made assumptions about fields besides patient name like practitioner name and appointment time being blank or having some other value that is not expected, and how to handle that.

How did you verify the AI output?

I verified the AI's output by testing it directly and comparing the results against the human written code, to identify where the gaps actually were.

What engineering work remained for you?

The engineering work remaining for me was understanding the correct functions, code structures, and objects well enough to catch mistakes AI might overlook and to critically review AI generated code using my own judgement. I was also left with refining it further for accuracy, flexibility, testing, and debugging. So inspite of using AI it is very necessary for me to have enough knowledge about the codes,objects,functions and details of the project for which the code is being written.
